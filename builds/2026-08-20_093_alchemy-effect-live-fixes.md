- 서버 plugins 폴더 적용: 하지 않음

## 수정 내용

- 흡혈 효과가 실제 전투 피해량을 기준으로 회복 계산하도록 계산 경로를 보강했다.
- 동상 효과가 기존 이동속도 Attribute 보정과 설정 가능한 Slowness 효과를 함께 사용하도록 수정했다.
- 감전 구속에 `root-duration-ticks` 설정을 추가하고 기존 `stun-duration-ticks`를 하위 호환 fallback으로 유지했다.
- 감전 root 상태가 이동 이벤트가 없어도 예약 해제되도록 정리했다.
- 감전은 피해 발생 시점에만 root를 시작하고 다음 pulse 전에는 자유 이동 상태가 되도록 유지한다.
- 상태효과 정의에 사용자용 설명 필드를 추가하고 `/effectlist` GUI에 실제 설명을 표시한다.
- YAML에 흡혈, 동상, 감전 및 전체 주요 상태효과 설명을 추가했다.

## 라이브 테스트

### 흡혈 물약

1. 흡혈 물약을 사용한다.
2. 사용 직후 `/rpg effect list`에서 흡혈 효과와 설명을 확인한다.
3. 플레이어 체력을 최대 체력보다 낮춘다.
4. 대상에게 직접 근접 피해를 준다.
5. 피해량에 비례해 체력이 회복되는지 확인한다.
6. 여러 피해량에서 회복량이 `피해량 x heal-ratio`와 일치하는지 확인한다.
7. 체력이 최대 체력을 초과하지 않는지 확인한다.
8. 투사체·범위 피해를 흡혈 대상에 포함할지 현재 설계와 일치하는지 확인한다.
9. 효과 종료 또는 제거 후 추가 피해로 회복되지 않는지 확인한다.
10. 재접속·사망 후 흡혈 효과와 회복이 중복되지 않는지 확인한다.

### 동상 물약

1. 동상 물약을 사용하고 `/rpg effect list`에서 설명을 확인한다.
2. 효과 전후 이동속도 차이를 평지에서 확인한다.
3. 기본 Slowness 효과가 실제 적용되는지 확인한다.
4. 효과 유지 중 이동속도 효과가 매 틱 중첩되어 점점 느려지지 않는지 확인한다.
5. 이미 Slowness가 있는 대상에게 사용했을 때 기존 효과가 부당하게 삭제되지 않는지 확인한다.
6. 동상 종료 시 커스텀 Attribute modifier가 제거되는지 확인한다.
7. 동상 종료 시 플러그인이 추가한 Slowness만 제거되고 외부 효과는 보존되는지 확인한다.
8. 사망, 로그아웃, 월드 이동, reload 후 이동속도가 원상복구되는지 확인한다.

### 감전 물약

1. 감전 물약을 사용한다.
2. 효과 적용 직후부터 첫 pulse 전까지 자유롭게 이동되는지 확인한다.
3. T+59까지 피해와 root가 없는지 확인한다.
4. T+60에 피해가 정확히 1회 발생하는지 확인한다.
5. 피해가 발생한 직후부터 20틱 동안만 위치 이동이 제한되는지 확인한다.
6. root 중 yaw·pitch 회전, 공격, 아이템 사용이 가능한지 확인한다.
7. T+80에 root가 해제되는지 확인한다.
8. T+80부터 다음 피해 직전까지 자유롭게 이동되는지 확인한다.
9. T+120에 두 번째 피해와 두 번째 20틱 root가 발생하는지 확인한다.
10. 피해 간격 중 계속 위치가 고정되거나 이동 이벤트가 무한 취소되지 않는지 확인한다.
11. 효과 제거, 사망, 로그아웃, 월드 이동, 서버 reload 시 root가 즉시 정리되는지 확인한다.
12. 서버 재시작 후 이전 root 상태가 남지 않는지 확인한다.

### 상태효과 목록

1. `/rpg effect list` 또는 `/effectlist`를 실행한다.
2. 활성 효과 아이콘에 효과명, 효과 ID, 실제 설명, 남은 시간, 스택, 출처가 표시되는지 확인한다.
3. 흡혈 설명이 피해 기반 회복을 설명하는지 확인한다.
4. 동상 설명이 이동속도 감소를 설명하는지 확인한다.
5. 감전 설명이 주기 피해와 피해 직후 구속을 설명하는지 확인한다.
6. 효과가 없는 경우 빈 상태 화면이 정상 표시되는지 확인한다.
7. 효과 갱신·종료 후 GUI를 다시 열었을 때 최신 남은 시간이 표시되는지 확인한다.
8. GUI에서 아이템을 꺼내거나 드래그할 수 없는지 확인한다.

# 도구 속도·생산량 분석

기준일: 2026-08-04
상태: 계산 경로 복원, 실제 블록 파괴 틱 측정 필요

## 현재 구현 경로

도구 강화는 `TOOL_EFFICIENCY`를 계산하고 `EquipmentActualEffectListener`가 플레이어 `BLOCK_BREAK_SPEED`에 `ADD_NUMBER` modifier로 적용한다. 현재 설정은 단계당 0.65 raw, 변환 계수 0.1이므로 +50에서 +3.25의 블록 파괴 속도 보정이 된다.

승급의 mining-speed, excavation-speed, logging-speed, farming-speed 옵션도 도구별 보정에 합쳐진다. 추가 드롭과 내구도 절약은 블록 이벤트에서 별도 처리되며, 설치 블록 공통 검증을 통과해야 한다.

## 목표 비교

단순 raw attribute 비교는 사용하지 않는다. 실제 비교 단위는 다음이다.

`블록 파괴 틱 = 도구 재질 + 블록 경도 + 효율 인챈트 + BLOCK_BREAK_SPEED + 서버 틱 처리`

비교군:

1. 같은 재질 기본 도구
2. 같은 재질 Efficiency V
3. +25 강화
4. +50 강화
5. +50 + 최대 승급
6. 커스텀 장비가 있는 경우 해당 장비

## 측정 표

| 측정 항목 | 입력 |
|---|---|
| 블록 | stone, deepslate, oak log, diamond ore 등 |
| 도구 재질 | wooden~netherite |
| 강화 | 0, 10, 20, 30, 40, 50 |
| 바닐라 효율 | 없음, I~V |
| 승급 | 0, 중간, 최대 |
| 반복 수 | 블록 종류별 최소 100회 |
| 측정값 | 평균 틱, 중앙값, 95백분위, 실패 횟수 |
| 경제값 | 시간당 유효 블록, 코인, 파편, 내구도 손실 |

## 현재 위험

- +50 도구가 Efficiency V보다 얼마나 빠른지는 실제 틱을 측정하기 전 판단할 수 없다.
- mining/logging 옵션이 생산량과 속도를 동시에 높이면 경제 효과가 합산된다.
- `bonus-drop-chance`는 정상 블록 파괴와 설치 블록 검증을 반드시 분리해 집계해야 한다.
- 범위 채굴·벌목 인챈트는 파괴 이벤트를 여러 번 만들 수 있으므로 이벤트 ID 중복 방지가 필요하다.
- 내구도 절약은 `PlayerItemDamageEvent`와 바닐라 Unbreaking의 상호작용을 별도 측정해야 한다.

## 경제 환산

시간당 생산량은 raw 블록 수가 아니라 다음으로 산정한다.

`실측 유효 블록/시간 × 블록당 활동 코인 + 부가 재료 기대가 - 수리비 - 이동·정리 시간 비용`

이전의 180·300·450회/시간 가정은 폐기한다. 이론 민감도는 0.5, 1, 2, 4블록/초를 각각 1,800, 3,600, 7,200, 14,400블록/시간으로 표시하되, 실측 전 최종값으로 사용하지 않는다.

# 통합 밸런스 분석 결론 및 후속 권고

기준일: 2026-08-04
상태: 분석 완료, 운영 수치 변경 보류

## 결론

현재 단계에서 확정할 수 있는 것은 공식과 측정 구조이지, 최종 코인·강화 수수료·보스 보상·신호기 가격이 아니다. 특히 다음 값은 실측 전 운영 적용 금지다.

- 채광 25코인/블록의 최종 적합성
- 0~50 강화 총 코인 수수료
- 강화석·마석의 그림자 가격
- 인챈트북·추출권·리롤권 가격
- 위더·엔더 드래곤 보상 가치
- 신호기 가격
- 원소 콘텐츠 진입 레벨
- RPG XP 속도 조정값

## 현재 구조상 우선순위

1. 전투 피해 계산 경로를 하나의 추적 ID로 계측해 강화·승급·인챈트 중복 적용 여부 확인
2. 도구별 실제 블록 파괴 틱을 측정해 +50과 Efficiency V의 차이를 확인
3. 활동별 유효 행동률과 수리비를 같은 세션에서 수집
4. 강화석·마석 공동 생산 모델로 병목과 잔여 재고 계산
5. 외부 설정의 건축 경로·마석 레시피·인챈트 상점 상태를 운영자 승인 후 마이그레이션
6. XP 공급원과 원소 진입 레벨을 플레이 시간 이정표에 맞춰 재계산

## 현재 권장안이 아닌 비교안

### 강화 수수료

25코인/블록을 유지한다면 강화 수수료는 생산 코인의 10%, 20%, 30%, 35%를 비교한다. 활동 코인을 먼저 낮추는 B안도 함께 산출하고, 사용자 승인 전에는 어느 안도 YML에 적용하지 않는다.

### 신호기

실측 시간당 코인을 `R`이라 할 때 후보는 `2R`, `4R`, `8R`이다. `R`은 이동·정리·수리·실패를 반영한 순수입으로 측정한다.

### XP

장비 성장과 동일 속도, 10% 빠름, 20% 빠름을 비교한다. 원소 진입 시점에 +강화·승급·복수 인챈트를 충분히 경험하는지 확인하기 전에는 배율을 수정하지 않는다.

## 운영 적용 상태

| 변경 항목 | 상태 |
|---|---|
| 소스 기본값 조사 | `SOURCE_DEFAULT_UPDATED` |
| 외부 YAML 대조 | `EXTERNAL_CONFIG_MIGRATION_REQUIRED` |
| 새 경제 수치 적용 | 적용하지 않음 |
| 외부 서버 수정 | 수정하지 않음 |
| 기존 플레이어 데이터 | 변경하지 않음 |
| 실제 플레이 검증 | `PLAYTEST_VERIFIED` 아님 |
| 밸런스 확정 | `BALANCE_PENDING` |

## 후속 실측 입력 형식

각 세션은 날짜, 플레이어 UUID 해시, 월드, 장비 ID, 강화, 승급, 인챈트 목록, 활동 시간, 이동 시간, 정리 시간, 유효 행동 수, 코인, 파편, XP, 내구도 손실, 사망·실패 횟수를 기록한다. 운영 데이터에 원본 UUID나 개인정보를 보고서로 복사하지 않는다.

## 이번 작업에서 하지 않은 것

- 경제 수치 최종 변경
- 외부 서버 YML 덮어쓰기
- 기존 아이템 PDC·강화·승급·인챈트 변경
- 몬스터 HP·피해·보상 변경
- 특수 장비 성능 변경
- 인챈트 상점 전체 구매 정책 변경

# 활동 속도 민감도 표 — 최신본

실측 전이며 최종 보상값이 아니다. 외부 YAML 현재값을 단순 대입한 참고표다.

## 채광 이론 범위

| 속도 | 유효 블록/시간 | 25코인 대입 참고값 |
|---:|---:|---:|
| 0.5/초 | 1,800 | 45,000 |
| 1/초 | 3,600 | 90,000 |
| 2/초 | 7,200 | 180,000 |
| 4/초 | 14,400 | 360,000 |

실측에서는 설치 블록, 실패 행동, 이동·탐색, 정리 시간을 제외하고 유효 행동만 기록한다.

## 외부 YAML 현재 보상

| 활동 | 보상 |
|---|---:|
| 채광 | 25/블록 |
| 벌목 | 20/블록 |
| 농사 | 15/성숙 작물 |
| 낚시 FISH/TREASURE/JUNK | 10/35/3 |
| 교배/도축 | 12/6 |

확률과 시간당 행동 수가 없으므로 시간당 코인은 balance-pending이다.

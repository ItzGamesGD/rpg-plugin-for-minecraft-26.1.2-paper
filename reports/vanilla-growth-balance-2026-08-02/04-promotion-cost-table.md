# 승급 비용과 공동 생산 — 최신본

현재 기본 `equipment-growth.yml`의 별 비용을 사용한 구조표다. 특수 장비는 제외한다.

| 장비군 | 최대 승급 정의 | 누적 승급석 |
|---|---|---:|
| 나무·돌·금 | normal-5 | 9 |
| 철 | advanced-5 | 23 |
| 다이아몬드 | heroic-5 | 76 |
| 네더라이트 | mythic-5 | 189 |
| 겉날개 | 없음 | 0 |

환산: 승급석 1개 = 강화석 1개 + 마석 1개, 강화석 1개 = 강화 파편 10개, 마석 1개 = 마석 파편 9개.

공동 생산식은 `max(강화석 필요×50, 마석 필요×112.5)`다. 네더라이트 최대 승급만 보면 강화석 9,450회 대 마석 21,262.5회이므로 마석이 병목이다. 0-50 강화까지 합치면 강화석 요구량이 커져 전체 병목은 달라질 수 있다.

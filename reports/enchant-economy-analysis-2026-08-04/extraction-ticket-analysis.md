# 인챈트 추출권 원가·가치 분석

기준일: 2026-08-04  
상태: 구조 계산 완료, 외부 수수료 불일치로 운영 적용 보류

## 1. 현재 레시피

소스 `crafting.yml`:

`enchant_extraction_ticket = magic_stone 4 + basic_promotion_stone 4`

`basic_promotion_stone = magic_stone 1 + basic_upgrade_stone 1`

따라서 하위 재료까지 풀면 다음과 같다.

| 자원 | 직접 요구 | 승급석 4개 환산 | 총 요구 |
|---|---:|---:|---:|
| 마석 | 4 | 4 | 8 |
| 강화석 | 0 | 4 | 4 |
| 마석 파편 | 0 | 36 | 36 |
| 강화석 파편 | 0 | 40 | 40 |

마석 1개는 마석 파편 9개, 강화석 1개는 강화석 파편 10개다.

## 2. 공동 생산 기준 시간

현재 활동 확률을 적용한 참고값:

- 마석 1개: `9 / 0.08 = 112.5` 유효 활동
- 강화석 1개: `10 / 0.20 = 50` 유효 활동
- 추출권 1개: `max(8×112.5, 4×50) = 900` 유효 활동

따라서 추출권 1개 제작의 재료 병목은 마석이다. 900회 동안 강화석은 기대 약 18개가 생산되므로 4개 사용 후 약 14개가 남는다. 이는 독립적으로 8마석과 4강화석의 시간을 더한 값이 아니다.

실제 시간은 활동별 유효 행동률을 `R`이라고 할 때 `900 / R`시간으로 계산한다. `R`은 아직 플레이 실측 전이다.

## 3. 현재 실행 비용

| 비용 | 소스 기본 | 외부 런타임 | 위험 |
|---|---:|---:|---|
| 추출권 | 1장 | 1장 | 동일 |
| 코인 수수료 | 6,000 | 0 | 외부 설정이 수수료를 제거 |
| 특수 장비 허용 | true | 별도 확인 | 정책 확인 필요 |
| 종결 장비 허용 | false | 별도 확인 | 현재 종결 장비 없음 |

추출 실행은 장비 UUID·인챈트·책 공간·추출권을 재검증하고, 복사본에 인챈트를 제거한 뒤 코인·티켓을 차감한다. 예외가 나면 장비·티켓·코인을 복구하는 rollback 경로가 있다. 다만 실제 서버에서 로그아웃·강제 종료·컨테이너 이동까지 검증해야 한다.

## 4. 추출 비용과 신규 재구축 비교

신규 재구축 비용은 책별 획득 경로가 설정에 없으므로 현재는 `미정`이다. 비교식은 다음으로 고정한다.

`추출 총비용 = 추출권 재료 + 추출 코인 수수료 + 적용 비용`

`신규 재구축 총비용 = 인챈트북 획득 비용 + 적용 비용 + 인챈트 강화 비용 + 슬롯 해금 비용`

`추출 비용 비율 = 추출 총비용 / 신규 재구축 총비용`

현재 신규 재구축 비용이 미정이므로 특정 인챈트에 대해 “추출이 싸다/비싸다”고 확정하지 않는다.

## 5. 적정 구조 비교

| 구조 | 장점 | 위험 | 현재 판단 |
|---|---|---|---|
| 고정 추출권 | 단순 | 희귀 책에는 저렴, 일반 책에는 비쌈 | 기본 후보 |
| 등급별 추출권 | 가치 차이 반영 | 아이템 종류 증가 | 후속 검토 |
| 기본권+추가 수수료 | 시스템 수 증가가 작음 | 수수료 누락 위험 | 외부 설정 정리 후 검토 |
| 인챈트 단계 연동 | 고강화 인챈트 보존가치 반영 | 복잡도·악용 검증 증가 | 후순위 |

현재 가장 안전한 방향은 고정 추출권을 유지하되, 실제 외부 수수료를 소스 정책과 일치시키고 추출권 중복·복제 테스트를 통과한 뒤 가격을 조정하는 것이다.

## 6. 반드시 검증할 악용 경로

- 추출 전 장비와 추출 결과 책의 PDC 보존
- 원본 장비에서 해당 인챈트가 정확히 1회 제거
- 같은 책을 다시 추출해 복제할 수 없는지
- 인벤토리 가득 참에서 티켓·코인·장비가 보존되는지
- 로그아웃·서버 재시작·GUI 강제 종료 후 부분 소모가 없는지
- 쉬프트 클릭·숫자키·더블 클릭·호퍼 이동 차단
- 장비 교환 또는 UUID 변경 후 실행 취소

## 7. 결론

추출권의 하위 재료 원가는 8마석·4강화석, 마석 파편 36개·강화석 파편 40개다. 다만 외부 수수료가 0으로 내려가 있어 현재 런타임은 소스 기본의 6,000코인 서비스 비용과 다르다. 이 불일치를 해결하기 전에는 추출권의 최종 가격을 입력하지 않는다.

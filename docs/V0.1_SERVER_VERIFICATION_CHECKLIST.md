# HyunseoRPG v0.1 서버 검증 체크리스트

이번 단계는 신규 콘텐츠 추가가 아니라 기존 장비 성장 효과가 실제 서버에서 유지되는지 확인하는 단계다.

## 장비 실제 효과

- [ ] 검, 도끼, 곡괭이의 강화 수치가 로어뿐 아니라 실제 계산에 반영된다.
- [ ] 도끼와 곡괭이의 채굴 시간이 강화 전보다 짧아진다.
- [ ] 도구를 교체하면 이전 도구의 채굴 보정이 남지 않는다.
- [ ] 갑옷 착용 후 최대 체력이 증가한다.
- [ ] 갑옷 제거 후 최대 체력이 원래 값으로 복구된다.
- [ ] 갑옷을 클릭, 드래그, 쉬프트 클릭으로 장착·해제해도 같은 결과가 난다.
- [ ] 피해 경감 상한이 config.yml 설정값을 따른다.
- [ ] 피해 TextDisplay가 대상 주변에 제한된 범위로 표시되고 0.8초 후 사라진다.

## 성장 데이터 보존

- [ ] 강화, 승급, 옵션, 인챈트 후 PDC와 로어가 유지된다.
- [ ] 수리 후 내구도만 변경되고 성장 데이터가 유지된다.
- [ ] 인벤토리가 가득 찬 상태에서 GUI 종료 또는 수리 결과가 유실되지 않는다.
- [ ] 재접속 후 장비 성장 상태와 실제 효과가 동일하다.

## 입력과 바닐라 충돌

- [ ] 커스텀 삼지창만 RPG 입력을 우선 처리한다.
- [ ] 일반 삼지창은 불필요하게 차단되지 않는다.
- [ ] 활 우클릭 발사와 인챈트 입력이 충돌하지 않는다.
- [ ] 바닐라 인챈트 테이블과 모루 우회가 차단된다.

## 던전과 리로드

- [ ] /rpgdungeon list, enter, info, boss, leave가 동작한다.
- [ ] 던전 몹 처치 수가 중복 증가하지 않는다.
- [ ] 던전 완료 보상이 한 번만 지급된다.
- [ ] /rpg reload all 후 장비 성장, 수리, 인챈트, 던전 설정이 반영된다.
- [ ] 잘못된 YAML reload 시 기존 설정이 유지되고 오류가 로그에 남는다.

## 테스트 기록 원칙

- 서버 플레이 테스트 전 항목은 미검증으로 기록한다.
- Paper 콘솔 오류, 재현 순서, 사용한 아이템 ID를 함께 기록한다.
- 기존 빌드는 보존하고 새 빌드만 builds 폴더에 저장한다.

# HyunseoRPG v0.1 Progression Loop

## Canonical flow

`vanilla activity -> upgrade fragments -> crafting -> upgrade stones -> anvil enhancement -> hunting/boss content -> promotion/magic stones -> promotion/enchantments`

The loop contract is declared in `progression-loop.yml`. It describes the route between systems; it does not move rewards or own transactions.

## Runtime ownership

- `ProgressionAccessRewardService`: awards `basic_upgrade_fragment` from configured vanilla activities.
- `ProfessionRecipeService`: converts fragments into `basic_upgrade_stone` through configured recipes.
- `MobRewardService`: base/class experience, coins, mob drops, and hunting-ground multipliers.
- `ShopService`: coin or item-currency transactions.
- `EquipmentEnhancementService`: consumes `basic_upgrade_stone`.
- `HuntingGroundSessionService`: consumes the configured ticket and applies configured reward multipliers.
- `DungeonRewardService`: applies configured magic-stone and dungeon rewards.
- `EquipmentPromotionService`: consumes the configured promotion stone.
- `EnchantService` and the enchant shop: consumes `magic_stone` for enchant books.

Each service remains the owner of its own transaction. The progression registry only validates that the configured inputs and outputs are connected.

## Configuration contract

Each stage declares `inputs`, `outputs`, `recipes`, and `next` stages. The `sources` section declares outputs that originate outside the progression registry, such as vanilla activity and RPG mob rewards.

At enable and reload time the plugin validates:

- stage references and next-stage references
- item IDs used by the loop
- recipe IDs declared by progression stages
- that every item input has a declared upstream source or output
- the presence of the crafting stage and its recipe connection

Invalid IDs are logged as errors instead of silently becoming dead-end rewards.

## Current default chain

- Vanilla activity supplies upgrade fragments.
- Crafting converts fragments into upgrade stones.
- The anvil consumes upgrade stones and raises equipment growth.
- Hunting and shops provide coins, tickets, and additional progression resources.
- Dungeon completion provides magic stones and promotion rewards.
- Promotion consumes promotion stones and unlocks further equipment growth.
- The enchant shop consumes magic stones and provides enchant books.

Prices, drop rates, and reward amounts remain in their existing YAML files. Migration changes configuration structure and legacy data; it does not silently remove player items. After the canonical configuration has been verified, `/rpg migrate legacy --apply` moves obsolete live-root files into `archive/legacy/<timestamp>` so they can be restored if needed.

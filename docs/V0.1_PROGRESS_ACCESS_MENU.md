# HyunseoRPG v0.1 접근 루프

## 기본 흐름

`바닐라 활동 -> 강화석 파편 -> 바닐라 제작대 강화석 제작 -> /rpg 또는 Shift+F -> 장비 성장 -> 사냥터/던전`

## 강화석 파편

- 대상 활동: 채굴, 벌목, 농사, RPG 몹 사냥, 낚시
- 활동별 확률: `progression-loop.yml`의 `access-materials.activities`
- 아이템 ID: `basic_upgrade_fragment`
- 기본 제작: 파편 10개 -> `basic_upgrade_stone` 1개
- 강화 비용, 강화 확률, 승급석 비용은 이번 작업에서 변경하지 않음

## 통합 메뉴

- `/rpg`: 통합 메뉴
- Shift+F: 통합 메뉴
- 상점: 기존 `ShopGuiService` 연결
- 장비 성장: 기존 `EquipmentGrowthGuiService` 연결
- 던전: 기존 `DungeonSessionService` 연결
- 생활 직업: 기존 `ProfessionService` 정보 연결
- 스탯: 기존 `StatGuiService` 연결

일반 F 입력은 기존 스킬 입력과 분리하고, Shift+F만 통합 메뉴가 취소·처리한다.

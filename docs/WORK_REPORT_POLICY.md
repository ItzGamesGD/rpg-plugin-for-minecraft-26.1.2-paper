# HyunseoRPG 작업 및 보고 규칙

## 배포 규칙

- 직접 플레이 검증이 불가능한 동안 서버 `plugins` 폴더의 기존 JAR를 덮어쓰지 않는다.
- 성공한 빌드는 `builds/`에 `YYYY-MM-DD_번호_기능요약.jar` 형식으로 저장한다.
- JAR와 동일한 이름의 Markdown 변경 기록을 함께 저장한다.
- 변경 기록에는 SHA-256, 수정 파일, 수정 내용, 미검증 테스트를 포함한다.
- 실제 서버 적용은 사용자가 명시적으로 요청한 경우에만 진행한다.

## 모바일 작업 보고 형식

모바일에서 요청한 작업은 대화창에 다음 항목으로 보고한다.

1. 기존 구조 분석
2. 이번 작업과 충돌한 부분
3. 재사용한 기존 기능
4. 새로 수정·구현한 기능
5. YAML 및 데이터 변경
6. PDC 또는 저장 구조 변경
7. 구조상 위험 요소
8. 빌드 결과
9. JAR 파일 경로
10. SHA-256
11. 실제 서버 미검증 항목
12. 다음 테스트 순서

플레이 테스트를 하지 않은 기능은 반드시 `미검증`으로 표시한다.

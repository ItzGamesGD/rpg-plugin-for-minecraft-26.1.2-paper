# HyunseoRPG v0.1 알파 테스트 패키지

## 관리자 테스트 명령어

모든 `/rpgtest` 명령은 `hyunseorpg.admin.test` 권한이 필요하며 기본값은 OP다.

```text
/rpgtest give <플레이어> <아이템ID> [수량]
/rpgtest coins <플레이어> <수량>
/rpgtest setcoins <플레이어> <수량>
/rpgtest hand [플레이어]
/rpgtest dungeon start <던전ID> [플레이어]
/rpgtest dungeon end [플레이어]
/rpgtest dungeon complete [플레이어]
/rpgtest dungeon status [플레이어]
/rpgtest reload [설정ID]
```

주요 테스트 아이템 ID:

```text
basic_sword
basic_bow
basic_spear
basic_axe
basic_upgrade_stone
basic_promotion_stone
magic_stone
enchant_book_blade_throw
enchant_book_light_greatsword
enchant_book_laser_arrow
hunting_ground_ticket
miner_pickaxe
miner_pickaxe_advanced
```

`/rpgtest hand`는 주손 장비의 강화 단계, 승급 단계, 인챈트 슬롯, 일반 옵션, 특수 옵션을 출력한다.
`/rpg give <itemId> [amount]`와 `/rpg reload <설정ID>`는 기존 명령으로도 사용할 수 있다.
던전의 상세 개발 명령은 `/dungeonadmin`, 사냥터는 `/huntingadmin`을 사용한다.

## 고정 알파 테스트 동선

1. 새 플레이어로 접속하고 기존 플레이어 데이터가 없는지 확인한다.
2. `/profession list`와 `/profession info`로 직업 목록 및 초기 상태를 확인한다.
3. `/rpgtest give <이름> basic_sword 1`로 기본 장비를 지급한다.
4. `/rpgtest give <이름> basic_upgrade_stone 64`와 `basic_promotion_stone 64`를 지급한다.
5. 일반 RPG 몹을 처치하고 경험치, 코인, 드롭이 지급되는지 확인한다.
6. 모루를 우클릭해 강화, 승급, 인챈트, 수리 메뉴가 열리는지 확인한다.
7. 강화 성공과 실패를 각각 확인하고 강화석, 성공확률, 강화 단계가 변하는지 확인한다.
8. 검, 활, 곡괭이, 도끼를 각각 강화하고 실제 피해·투사체·채굴 효과를 확인한다.
9. 강화 상한 도달 후 승급하고 승급석, 등급, 성급, 옵션, 슬롯을 확인한다.
10. 무기·도구·방어구별로 허용되지 않은 옵션이 붙지 않는지 확인한다.
11. `/rpgtest give <이름> magic_stone 10`과 인챈트 북을 지급해 장착과 실행을 확인한다.
12. 내구도가 감소한 장비를 수리하고 코인만 차감되는지 확인한다.
13. `/rpgtest dungeon start test_dungeon <이름>`으로 조건을 우회해 던전에 입장한다.
14. 던전 웨이브, 발광 몹, 처치 수, 제한시간, 사망·종료 처리를 확인한다.
15. `/rpgtest dungeon complete <이름>`으로 보상 지급 및 중복 지급 방지를 확인한다.
16. `/rpgtest reload all` 후 변경한 YAML 값이 실제로 반영되는지 확인한다.

## YAML 밸런스 조정 위치

| 조정 항목 | 파일 | 주요 키 |
|---|---|---|
| 몹 드롭률·코인 | `mobs.yml` | `drops.*.chance`, `reward.*` |
| 생활 직업 드롭률·활동 코인 | `professions.yml` | `activity-coin-rewards`, `drops.*.chance` |
| 상점 가격 | `shops.yml` | `buy-price`, `sell-price` |
| 강화 비용·확률 | `equipment-growth.yml` | `enhancement.initial-cost`, `cost-curve`, `start-chance`, `final-chance`, `fail-bonus` |
| 승급 비용·옵션 | `equipment-growth.yml` | `promotion.grades.*.stars-data.*`, `promotion.profiles.*` |
| 수리 비용 | `config.yml` | `repair.cost-per-durability`, `minimum-cost`, `allow-partial-repair` |
| 던전 입장 조건·시간·보상 | `dungeons.yml` | `requirements`, `duration-seconds`, `rewards` |
| 던전 마석 보상 | `dungeon-rewards.yml` | `clear-reward.base-reward`, `reward-per-level` |
| 사냥터 입장권·시간·배율 | `hunting-grounds.yml` | `ticket-item-id`, `time`, `rewards.experience-multiplier`, `rewards.coin-multiplier` |
| 사냥터 재입장·개체 수 | `hunting-grounds.yml` | `population.target-alive`, `respawn-delay-ticks` |

## 자연 발견 UX 점검

- [ ] 강화석, 승급석, 마석, 입장권의 이름과 설명이 인게임에서 한국어로 표시된다.
- [ ] 첫 획득 시 발견 메시지가 출력된다.
- [ ] 모루 메뉴에서 재료 부족, 성공, 실패, 수리 비용이 명확히 표시된다.
- [ ] 던전 입장권에 사용 방법과 소비 여부가 표시된다.
- [ ] 인챈트 북과 마석의 용도가 아이템 설명만으로 파악된다.

## 실패 기록 형식

```text
[단계]
[명령어]
[기대 결과]
[실제 결과]
[콘솔 오류]
[재현 횟수]
```

플레이 테스트 전 항목은 미검증으로 기록한다. YAML을 바꾼 뒤에는 같은 조건에서 한 항목씩만 비교한다.
